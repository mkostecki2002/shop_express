<h1>Shop Express</h1>

The application consists of a React and TypeScript frontend communicating with an Express.js and TypeScript REST API. The backend uses PostgreSQL with TypeORM for data persistence and provides endpoints for managing users, products, and orders.

The application implements JWT-based authentication and authorization, allowing users to securely access protected resources. It also includes AI-powered generation of SEO-friendly product descriptions, integrating an LLM into the product management workflow.

The project is containerized with Docker and Docker Compose, providing a consistent development environment for the frontend, backend, and database.
